# TinyWarp 0.1.2：关于页与设置入口

2026-11-13，发布 `0.1.2（构建 5）`，适用于 macOS Apple Silicon。用户授权推送与发布，日常升级由用户通过内置“检查更新”完成。

## 用户可见变化

- 关于页使用已选定的亮色立体 TinyWarp 字标，较首轮候选放大约 50%，保持比例与透明背景。
- 普通设置入口默认打开外观；已有设置标签继续复用并切回外观，明确指定功能、快捷键和关于等页面仍有效。
- 关于页增加 GitHub 仓库链接，与更新器使用同一仓库地址。

设计选择、资源哈希与入口实现见 [品牌记录](branding.md)。应用身份继续为 `dev.warp.WarpOss`，数据目录、SQLite schema、签名公钥及更新安装协议均沿用；未引入依赖或锁文件变化。

## 源码、构建与验证

标签 `v0.1.2` 指向 `c6f52c38f37720d9b023a63c2cf38bde9fa53dc7`。正式优化包从该干净提交构建，使用 Rust 1.92.0、锁文件、`--no-default-features --features tinywarp_gui -j2` 与应用 opt3，构建在日常 TinyWarp 现有窗口的专用标签中执行，没有覆盖运行中的应用。

本轮重新运行 69 项定向 Rust 回归与 5 项 Python 版本／打包测试，均通过。设置与关于页的真实显示 GUI 回归、深浅主题截图和两组严格 Clippy 复用已验证的 `6b24fbdcf` 源码证据；之后产品源码未再变化，仅版本配置由 0.1.1／4 更新为 0.1.2／5。复核文件与步骤记录一致，不将复用证据说成本轮重新运行。

正式包另核对系统版本、资源版本、arm64、ad hoc 签名、完整内嵌 PNG、两份项目许可、第三方许可汇总及精确源码定位。临时 HOME、独立应用身份和真实数据路径禁令下，3 个测试标签、3 个终端 pane、2 条测试历史与配置保持，三个 shell 的外部 CLI 字节输入输出通过。旧日期 inbox 保留且跳过，发布前公开检查返回暂无更新；测试实例正常退出码为 0。

正式包另经原生菜单实际打开关于页，已看到 0.1.2（构建 5）、放大的字标与 GitHub 入口；普通设置入口从关于页切回外观，关闭临时设置标签后原三个终端标签仍在。

早期验证辅助脚本曾误要求外部 PNG 文件，已按 `warp_assets` 的二进制嵌入方式修正；ZIP 内二进制哈希与已确认完整字标字节的候选一致。旧临时 fixture 已不存在，因此改用仓库公开三标签夹具；首次初始化补入默认隐私规则后正常退出，再以初始化后的配置哈希验证恢复，全部通过。未弱化配置保留断言，也未重建已通过的正式二进制。

许可生成器仍对旧 `GPL-2.0` 标识输出解析提示，最终成功生成 1,356,540 字节许可汇总，内容 SHA256 与公开 0.1.1 所用汇总一致。
