# TinyWarp 0.1.3：设置中文与菜单头像

2026-11-16，`0.1.3（构建 6）` 已[公开发布为 Latest](https://github.com/sty20030818/TinyWarp/releases/tag/v0.1.3)，面向 macOS Apple Silicon。正式优化包已完成构建与隔离验收；日常安装本轮未替换，升级仍由用户通过内置“检查更新”完成。

## 本版范围

- 修复设置中更换应用图标后 Dock 图标不更新的问题，正式包补齐 Dock 插件与替代图标资源，沿用现有图标选择。
- 设置标签及本地终端快捷键动作使用中文，继续支持中英文名称与按键搜索，保留已有自定义按键及内部 ID；已停用的 AI、云与独立编辑器动作从候选中隐藏，原注册与处理器保留。
- “Shell 与 SSH 增强”页面说明子 Shell／SSH 的命令分块、输入编辑及远程辅助程序安装选择，不改变现有设置键和连接行为。
- “设置 → 外观”支持选择菜单头像，预览与右上角菜单同步，重启后保留，并可恢复默认齿轮；自定义头像使用透明底，去除主题色圆底及常驻说明。
- 修复 macOS 原生图片选择面板初始化时重入应用上下文导致的崩溃。

图标修复的根因及原生证据见 [应用图标修复](app-icon-fix.md)，设置、图片存储和功能验收细节见 [设置中文与菜单图片](settings-personalization.md)。本版继续使用 `dev.warp.WarpOss`，沿用原数据目录、SQLite schema、更新公钥及安装协议。

## 检查与功能基线

101 项定向 Rust 测试为本轮功能基线，覆盖菜单图片、设置标题与搜索、完整生产快捷键注册、中英文搜索、自定义按键、菜单更新及应用图标回归。完整快捷键回归与真实页面共用候选生成逻辑，确认保留动作均有中文、停用动作被排除且原注册保留；图片回归使用临时目录覆盖导入、重启读取、失败保留、坏文件回退、缓存更新及恢复默认。

用户验收后，头像仅在菜单与设置预览两处调用点调整背景并删除常驻说明；沿用上述 101 项功能基线，不将其写成样式调整后重新运行。后续视觉候选另通过应用构建、应用严格 Clippy、8 项中文目录测试、打包签名检查及最终格式化，并实际导入带透明区域的 PNG，观察菜单与预览均无蓝色圆底，常驻说明已移除。

本次正式候选另运行 5 项实际打包检查，覆盖完整包、预构建安装、重复安装拒绝、错误入口类及缺失图标，全部通过。

[本次 TinyWarp CI](https://github.com/sty20030818/TinyWarp/actions/runs/43846390734) 对同一源码提交执行成功，使用 `macos-15` 的 ARM64 runner。云端通过 5 项版本检查、5 项原生插件 fixture 检查、依赖边界检查、8 项中文目录测试及该 crate 的严格 Clippy；依赖检查实际覆盖 829 个正常构建包。该工作流是轻量 CI，没有构建或启动 TinyWarp 产品，也不替代应用级回归和以下正式包验收。

## 正式包 GUI、CLI 与数据保留

正式二进制的隔离副本复用已有测试 Profile，原生关于页已观察到 `0.1.3（构建 6）`。终端中执行 `pwd` 与 `printf` 正常，原 2 个标签保留，头像选择与验收前一致，SQLite `quick_check=ok`；正常退出码为 0。正式候选本身的元数据与内容保持不变，没有为原生验收改写交付包。

该结果证明隔离 Profile 下的正式二进制可以启动、显示正确版本、运行外部 CLI 并正常退出，不代表日常应用已经完成升级。日常安装未被替换，未迁移、恢复或清理日常数据；用户仍自行选择“检查更新”，下载校验完成后选择“重启并更新”，再验收现有设置、历史、自定义快捷键及会话。

## 交付边界

本版继续采用 ad hoc 代码签名与 SSHSIG 更新认证，尚未完成 Developer ID 签名、公证或首次浏览器下载的 Gatekeeper 验收；VoiceOver、完整缩放矩阵、全工作区及跨平台验证也未完成。正式包隔离验收不替代用户通过日常更新入口完成的升级验收，也不构成偶发 Tab 丢失已经修复的结论。

原始构建、产物、CI 与隔离验收证明保存在本机忽略目录 `.note/0.1.3/`。公开记录仅保留必要的结果与发行物哈希，不公开头像哈希、私人数据库路径或备份内容。
