## 兼容处理

- `MenuItemFields::with_display_label` 为明确的固定菜单提供中文显示；原 label 继续用于按名称选择、近似相等和 SavePosition，实际渲染及无障碍使用中文。类型投影携带稳定标签，不按英文全局替换用户命名。
- 模糊描述匹配在应用层复用同一函数，覆盖命令动作、快捷键筛选和新会话；英文别名只用于召回，不能把英文下标套到中文显示上。新会话全文索引把显示与别名分开，中文查询复用模糊路径。
- 历史筛选的 core 语法保持英文稳定值；中文只在应用显示层映射。运行中/已结束等英语搜索投影保留在显示范围之外。
- 本地设置的 enum/serde 值、action、context、真实快捷键查询、SSH telemetry 字段保持原样；按显示 label 选择的 UI 查询同步使用中文，不改保存值。
- 默认分组名只在模型没有自定义名称时显示中文；明确命名为 `New Group` 的用户数据不翻译。布局/标签配置模型、YAML/TOML 模板和默认名称保持原样。
- 动态文案保留数量、文件名、命令和错误详情。具名替换使用固定模板；单变量只替换一次，目录与快捷键的组合先插入受限快捷键、最后插入目录，避免再次解释用户路径。不建设通用插值语言。设置错误原始 `Display` 继续用于诊断，UI 描述单独汉化。
