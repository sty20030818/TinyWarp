# TinyWarp L3C5：本地 GUI 启动读取范围

2026-11-11，基于 C4 `ed47909f6`。本批为纯本地终端增加独立的持久化读取范围。修正终端共用数据边界及实验缓存回写问题后，单元、GUI、严格检查和独立候选验证均已通过。

## 读取与保存边界

新增 `PersistedDataScope::LocalGui`。由已有本地终端策略与启动模式共同选择：OSS 本地 GUI／显式本地测试采用 LocalGui；普通完整 GUI、命令行 SDK、远程代理、TUI 和远程 daemon 沿用其原有范围。策略在纯函数中集中选择，启动路径不再自行复制判断。

LocalGui 复用原会话恢复查询，保留窗口、标签、标签组、固定状态、分屏、工作目录、面板描述和命令块；历史沿用原查询排序与元数据。本地项目路径列表及用户忽略的 shell 命令建议仍有终端消费者，继续读取；忽略建议在 SQL 层只读取 ShellCommand，AIQuery 记录保留在磁盘。旧 AI／账号／编辑器 pane 的描述与命令块中的原始 AI 字段仍保存，后续继续使用已有不可用视图，不会为了跳过云加载而抹除旧快照。

`AppState.running_mcp_servers` 是正常会话快照会重新写回的原始 UUID 列表，继续读取并交给现有保留逻辑；这不代表启动 MCP 服务。完整安装记录与待恢复服务清单不加载。若把这个 UUID 列表直接清空，正常保存会删除旧元数据，因此本批明确将它留在最小会话范围。

终端所需的本地数据读取完成后直接返回，跳过云对象及权限上下文、团队／工作区／用户资料、同步动作、服务端实验、AI 输入历史、代码索引、LSP 状态、Agent 会话／任务／摘要回填、AI 项目规则与 MCP 安装／恢复数据。被跳过的组在内存中为空；必要 SQL 出错仍返回原错误，不能以默认值代替读取失败。

`PersistedData` 的 Default 用于明确未请求的数据组，并复用到已有索引专用范围；完整读取流程的云数据查询与命令历史查询顺序保留。本地模式的服务端实验模型不再应用或回写实验状态，防止未加载的空缓存覆盖旧记录；原版仍保留正常更新和明确清空的行为。没有迁移、删表、旧记录清理或新的依赖。写入线程保持正常会话、命令及原始块元数据的保存能力。

## 验证中发现并修正的问题

初轮审查发现项目路径与忽略的 shell 建议仍由终端消费，已从跳过范围中移出，并增加恢复断言；中断了该轮 integration 编译，相关旧结果独立归档，最终记录只采用修正后版本。

旧记录原生复验随后发现 `ServerExperiments::new_from_cache` 会经 `apply_latest_state` 将传入状态再次写回数据库，未加载的空缓存因此清空了实验记录。现于模型所有者处按本地终端策略停止实验应用和回写；新增回归确认本地模式没有实验副作用或持久化事件，同时非本地模式仍正常持久化、保留服务器明确清空的行为。修正后重新运行了相关单元、GUI、严格检查及候选构建，并通过已知／未知实验值的真实启动退出复验。修正前候选与失败证据均保留。

一次截图因测试窗口不可捕获而失败；仅修正隔离窗口激活／AXRaise 和有界等待，未改产品代码或重跑源码构建。最终截图与全部原生检查通过。
