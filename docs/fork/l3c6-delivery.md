# TinyWarp L3C6：内置编辑器语言服务专用运行链

2026-11-11，继续基于 `sty20030818/local-terminal` 分批裁剪剩余大模块。本批以前一阶段 C5 提交 `5bf0113c8` 为基线，仅处理内置语言服务器的发现、安装和启动能力；终端、外部 CLI、原有配置及数据库格式保留。

## 实现范围与取舍

`lsp` 增加默认开启的 `builtin_servers` feature，将五类内置候选实现与安装模块置于该边界：rust-analyzer、gopls、Pyright、TypeScript Language Server、clangd。Node.js 下载／安装运行链及安装器的专用依赖改为可选。工作区关闭继承默认；完整应用通过默认 `editor_language_servers` 显式恢复，独立 LSP crate 默认也保持完整能力。TinyWarp 使用 `--no-default-features --features tinywarp_gui`，不编入这些具体实现。

共享的协议、编辑器模型、语言类型和 `LSPServerType` 全部持久化名称仍保留；没有用空服务器或虚假成功实现替代。精简构建的候选创建和命令解析会明确返回不可用错误，完整构建继续使用原有实现。发现、安装、状态检测调用点已同步错误处理；现有本地终端运行时入口限制继续生效。

实际 macOS arm64 产品 normal/build 依赖图由 894 → 891 项，无新增，退出 `node_runtime`、`tar`、`xattr`；完整 GUI 图仍为 975 项。ZIP、其他压缩／归档能力及共用文件、网络库仍有消费者，未扩大删除范围。依赖边界脚本新增禁止 `node_runtime` 回流。Cargo.lock 没有改变。

这不会卸载系统 Node.js、npm 或已安装的语言服务器，也不会拦截 shell 中运行项目和任意外部 CLI。尚未移除整个共享编辑器、LSP 协议、AI／云源码或其全部依赖；后续仍按消费者分批推进。
